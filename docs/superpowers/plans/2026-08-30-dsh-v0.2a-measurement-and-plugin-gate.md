# DSH v0.2a Measurement and Plugin Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the keyless v0.2a foundation: versioned context/evaluation contracts, a reproducible TypeScript/JavaScript baseline corpus, deterministic metrics, safe repository-path policy, and a compatibility report for the pinned `dsh-lsp-actions` candidate.

**Architecture:** Keep v0.2a as a pure, provider-free workspace package layer. It defines internal snapshot/index contracts separately from bounded model-visible projections, and it records plugin compatibility as data rather than installing a community plugin into the default profile. v0.2b will consume these contracts to implement read-only code intelligence; v0.2c will later add context blocks and persistence.

**Tech Stack:** TypeScript ESM, Node.js 24, pnpm workspace, Vitest, exact `@dqbd/tiktoken@1.0.22` with the checked-in `cl100k_base` encoding, JSON fixtures, exact DSH `0.1.1-rc.2` metadata, and the existing Nix development shell.

**Spec:** `docs/superpowers/specs/2026-08-29-dsh-v0.2-token-economy-design.md`

## Global Constraints

- Keep DeepSeek Harness at exact `0.1.1-rc.2`; do not change `upstream/deepseek-harness`.
- Keep `pnpm test:provider` permanently keyless and disabled; v0.2a tests and checkers must not access credentials, OAuth, providers, or network endpoints. Dependency installation may use the reviewed lockfile and configured package source; it is not provider validation. If dependencies are already cached, use `pnpm install --frozen-lockfile --offline`.
- Do not modify `profiles/v0.1/cordis.patch.yml` or add a community plugin to the default profile.
- Treat external plugin code as untrusted host-level code; use the reviewed `dsh-lsp-actions` commit `ea0354ca444075b37b791bd8638fecdbc40fb5d0` only as an audited compatibility subject.
- Use repository-relative POSIX paths and reject absolute paths, traversal, NUL bytes, symlink escapes, ignored secret files, nested checkouts, binary files, and oversized files.
- Make all model-visible projections bounded, cursor-capable, provenance-carrying, JSON round-trippable, and deterministic.
- All tests use synthetic fixtures or local deterministic processes; no test may call a provider, credential store, or network endpoint. `pnpm install` is a setup action and must use the checked-in lockfile.
- Preserve the existing v0.1 Loader/replay, typecheck, build, profile, and provider-disabled checks.
